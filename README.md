### 2. useQuery vs useSuspenseQuery

**현재:** `useQuery` 사용 (명시적 로딩/에러 제어)

**질문:**
- 이 과제에서 `useSuspenseQuery`가 더 적합했을까요?
- 선언적으로 처리하는 것이 항상 옳은 방법인가요?
- 선택 기준은?
  - 단순히 `enabled` 필요 여부?
  - Error Boundary 구축 여부?
  - 프로젝트 규모/복잡도?
- `enabled` 불필요하면 무조건 `useSuspenseQuery`를 써야 하나요?
